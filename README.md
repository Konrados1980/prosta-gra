# Lot nad Rzeką

Prosta zręcznościówka w przeglądarce. Lecisz samolotem nad krętą rzeką i omijasz brzegi, wyspy i skały. Za złote kółka dostajesz +25 punktów. Masz 3 życia, a gra z czasem przyspiesza.

## Zagraj online

👉 **https://konrados1980.github.io/prosta-gra/**

## Jak uruchomić na komputerze

Kliknij dwa razy plik `index.html` i gra otworzy się w przeglądarce. Nic nie trzeba instalować.

## Sterowanie

- ← → lot na boki
- ↑ lot do przodu (szybciej)
- ↓ lot do tyłu (wolniej)
- P pauza
- Enter start i nowa gra
